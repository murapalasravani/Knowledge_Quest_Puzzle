# Knowledge Representation Unit 3 - Keyword Puzzle

An interactive word-search game based on
Knowledge Representation concepts.

## Features

- 8 important keywords
- Interactive word selection
- 3-minute countdown timer
- Completion and game-over messages
- Supabase-powered leaderboard
- Ranking based on remaining time

## Technologies Used

- HTML
- CSS
- JavaScript
- Supabase
- PostgreSQL
- REST API

## How to Play

1. Enter your player name.
2. Find all 8 hidden keywords.
3. Complete the puzzle before time runs out.
4. Check your leaderboard ranking.
